# Fast-Clone


**Fast Clone** is a Community Based Facebook Password Reset & Login Tool.


## 🛠️ Setup

Run the following commands in Termux to get started:

```bash
apt update && apt upgrade -y
pkg install python git -y
git clone https://github.com/inception09/Fast-Clone
cd Fast-Clone
chmod +x ./neko.sh
./neko.sh

```
